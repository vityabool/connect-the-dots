# Facilitator guide — Connect the Dots: The Human Network

For the person running the game in the room. No technical knowledge needed.

## Before the event (10 minutes)

1. Open the app and choose **Facilitator? Sign in**. Sign in with any Microsoft account (personal or work).
2. **Create a game**: give it a name such as "Leadership offsite, Oct 2026". The game gets a **6-digit code** and stays open for **3 days**.
3. **Add the participants**: upload a `.txt` file with one name per line (for example `Anna Koval`), or paste the names. Save the file as **UTF-8** (in Notepad: Save As > Encoding: UTF-8) so names with accents or Cyrillic letters stay correct; the app refuses files that are not UTF-8. Names must be unique; duplicates are skipped automatically. You can add or remove people at any time, even during the game.
4. **Check the topics** (optional): every new game starts with ten topics, such as "🎾 Play tennis" and "🐕 Have dogs". Delete or merge the ones you do not want, add your own (one per line), or press **Restore the default topics** to bring back deleted defaults. Topic names can have up to 30 characters; a longer name is not refused but shortened and ends with "…". Players can add their own topics during the game.
5. In **Timer and big screen**:
   - set the **timer length** (default 30 minutes),
   - click **Generate a short link with is.gd** to get a short link to the join page (for example `is.gd/aB3x9Q`), or paste a link from another service; press **Save settings** to show it on the screen,
   - edit the **rules** shown on screen if you like (one rule per line; leave empty for the defaults),
   - tick **Show names** if you want names on the projected graph,
   - press **Save settings**.

## During the event

1. Open **Open Timer screen** in a new window and drag it to the projector. Press **Fullscreen** there.
   It shows the countdown, how to play, where to join (short link, 6-digit code and a QR code) and the live network graph with new lines appearing as people connect.
2. Start the round: press **Start timer** on the game page (you can **Pause** and **Reset** it).
   When time is up the screen shows "Time's up!" (turn on **Sound** on the Timer screen for a beep). **The game does not stop**; people can keep connecting.
3. Players join on their phones: open the link or scan the QR code, enter the code, pick their name, then add connections (person + topic). They only see their own connections.
4. Keep an eye on the counters on the screen: the goal of round 3 is **one group** and **0 people not connected yet**. People without any connection pulse with a yellow ring on the graph, so the room can see who still needs a conversation.

### Suggested rounds (from the game description)

| Round | Time | Goal |
|-------|------|------|
| 1. Find Your People | 10 min | Discover and record commonalities |
| 2. Unexpected Connections | 10 min | Find unusual links ("we work at Microsoft" no longer counts) |
| 3. Connect the Network | 10 min | Everyone belongs to one connected network |

Bonus prompts you can read out: find someone who lived in three countries, has an unfamiliar hobby, changed industries, or shares an experience with five or more colleagues.

### Tidying up during the game

- **Wrong or duplicate topic** ("Dogs" and "Have dogs"): in the Topics list use **Merge into…** to combine them; the connections move to the topic you keep.
- **Remove a topic**: **Delete topic** also deletes the connections made with it (the confirmation tells you how many).
- **Remove any connection**: use the Connections list (search by name or topic).
- A player who picked the wrong name can tap **Wrong game? Start over** and join again.

## At the end

Open **Open results** (a new window). Nine views, each with an **Export image** button (PNG):

| View | What it shows |
|------|---------------|
| Network | Everyone with names, lines colored by topic, bigger dots for well-connected people |
| Top topics | Bar chart of the most used topics; click a bar to highlight it on the network |
| Super-connectors | Leaderboard and the "Connector of the day" |
| Unexpected links | Connections on rare topics (used once or twice) |
| Groups | How many separate groups remain, who is still alone, and the "Everyone is connected!" moment |
| Topic spotlight | Pick a topic and see only the people who share it |
| Who met whom | A grid of all pairs that are connected |
| Replay | The network growing again, connection by connection (play or drag the slider) |
| Summary | One slide with the headline numbers |

## After the event

- A game closes automatically after its expiry date (default 3 days). Use **Extend by 3 days** on the game page to keep it open longer (up to 30 days from today). If you reopen a game that has been expired for a while and its 6-digit code has meanwhile been given to another game, your game gets a new code (shown on the game page).
- **Delete game** permanently removes the game and all its data (participants, topics, connections). Do this when you no longer need the results.

## Good to know

- Each facilitator only sees their own games.
- Open the app a few minutes before the session: the very first request after a quiet period can take a few seconds.
- If the network drops, screens show "Connection lost. Reconnecting…" and catch up by themselves.
- Everything works on phones; the Timer screen and the results are designed for a projector.
