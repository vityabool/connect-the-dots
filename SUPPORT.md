# Support

**Connect the Dots is free software provided "as is", without support, warranty or service level.** There is no help desk. The
people who run and maintain it do so on a best-effort basis, when time allows.

## What you can do

| You want to ... | Do this |
|-----------------|---------|
| Learn how to play or run a game | Read the [facilitator guide](docs/ADMIN_GUIDE.md) and the *How to play* page of the site |
| Report a bug | Open a [bug report](../../issues/new/choose) |
| Suggest an idea | Open a [proposal](../../issues/new/choose) |
| Complain or give feedback (usability, wording, accessibility) | Open a [feedback issue](../../issues/new/choose) |
| Run your own copy | See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md); you are on your own, but the tests and docs help |
| Report a **security** problem | Use a [private security advisory](../../security/advisories/new) (see [SECURITY.md](SECURITY.md)). Never a public issue |
| Make a **privacy request** (see below) | Email the contact address on the site's [privacy policy](https://www.connect-the-dots.top/privacy#contact). Never a public issue |

## What to expect from issues

- Issues are the place for **bug reports, proposals and complaints**. They are public, which also lets other people find
  existing answers and add their voice.
- Issues are read when time allows. **A reply, a fix or a deadline is never guaranteed**, and a request may be declined.
  Please do not ask for status updates or for individual help.
- Please search existing issues first, use the templates, include steps to reproduce, and be kind (see the
  [Code of Conduct](CODE_OF_CONDUCT.md)).
- **Never put personal data in an issue** (real participant names, email addresses, game codes of games that are still
  running) and never post secrets.

## Privacy requests

If your name is on a game's participant list and you want to see, correct or delete your data, first ask the facilitator
of that game: they control it. You can also write to the operator of the service; the contact address is in the
[privacy policy](https://www.connect-the-dots.top/privacy#rights). Requests sent as public issues will
be removed, because issues are visible to everyone.
